# 커스텀 곡 주입 시스템 분석

곡 선택 화면의 곡 목록에 커스텀 앨범을 끼워 넣고, 선택한 커스텀 곡을 플레이 가능한 상태로 만드는 흐름을 설명합니다.
(2026-09-28 코드 기준. 훅 소유 관계의 정본은 [HOOK_MAP.md](../maintenance/HOOK_MAP.md))

## 전체 흐름

```
게임 시작 (SceneDetector.OnInitializeMelon)
  └─ hwa 스캔, BMS 전체 파싱                      → 앨범_관리_시스템_분석.md
곡 선택 씬 (MusicSelectScene_Hasegawa)
  ├─ cMusicSelectScrollView.initializeMusicDataByDefault  [postfix: MusicScrollViewHooks]
  │    ├─ 원본 곡 목록에서 캐릭터별 첫 곡 등록
  │    └─ 앨범마다 커스텀 항목(MusicID 54~) 추가
  ├─ 커서 이동 → noticeChangedMusic                       [postfix: AudioClipPatch]
  │    └─ 커스텀이면 앨범 선택, 프리뷰 음소거, 커스텀 프리뷰/아트워크
  ├─ 곡 결정 → coOpenPreMusicStartWindow                  [prefix: GameFlowHooks]
  │    └─ mCurentMusicId를 "템플릿 곡"(같은 캐릭터의 첫 원본 곡) ID로 바꿈
  ├─ requestOpenWindow                                     [postfix: GameFlowHooks] 시작 창 아트워크
  └─ startRythmGame → setCurrentSelectDataToGameData      [postfix: GameFlowHooks] 세이브 ID 보정
플레이 씬 (FairyModeScene + PlayMovieScene + RenderCutinScene)
  ├─ createAllNote  [prefix: NoteArrayHooks]  BMS 노트로 교체
  ├─ BgmBgaInjector 루프: BGM/BGA 주입           → BGM_BGA_관리_시스템.md
  └─ coMonitorGameEnd [postfix 래핑]: 종료 시간 보정 → 게임_종료_시간_조정_가이드.md
결과 씬 (RythmGameResultScene)
  └─ initializePreFade [prefix/postfix: ResultSceneUpdaterPatch] 세이브 ID·제목·레벨·아트워크
```

## 1. 곡 목록에 추가 (`MusicScrollViewHooks`)

**대상**: `cMusicSelectScrollView.initializeMusicDataByDefault()` (private) **postfix**

원본은 `mCellHaviableMusicDataList`를 비우고 원본 곡으로 다시 채웁니다. `initialize()`와
`doFilterMusicList()`(정렬/필터)에서 모두 호출되므로 씬 한 번에 여러 번 실행됩니다.
postfix 시점에는 원본 곡만 있고 정렬·필터는 그 뒤에 적용되므로, 커스텀 곡도 원본과 같은 정렬·필터 규칙을 따릅니다.

postfix가 하는 일:

1. `RegisterArtistFirstSongs()`: 목록을 앞에서부터 보며 캐릭터(`artistID`)별 첫 곡의 MusicID와 제목을 등록합니다.
2. 기존 커스텀 항목(MusicID 54~511)을 먼저 지웁니다(중복 주입 방지).
3. 목록 첫 곡의 `MusicSelectData`(struct)를 복사해 앨범마다 항목을 만듭니다.

항목에 넣는 값:

| 필드 | 값 |
|------|----|
| `musicID` | `54 + 순번` (최대 511, 넘으면 경고 후 건너뜀) |
| `songTitle`, `songTitleForSort` | `SongInfo.Title` → 없으면 폴더 이름 |
| `songTitleRuby`, `songTitleRubyDirect` | 빈 문자열 (제목 위 작은 읽기 표기 제거) |
| `musicLVArray` | `info.txt`의 easy/normal/hard/expert 숫자 (없으면 0) |
| `haveMV` | 앨범에 mp4가 있으면 true |
| `defaultSortPrio` | `10000 + MusicID` (기본 정렬에서 원본 뒤) |
| `sorceTitle` | `OTHER` |
| `artistID` | `info.txt` 캐릭터가 `Morpho`/`Roro`/`Luxair`(한글 `르호`/`룩시아` 포함)면 그 값, 아니면 템플릿 값 유지 |
| `isFull`, `isCurrentLock`, `isNeedDispNew` | false |
| `highScoreArray`, `clearBadgeArray` | 새 빈 배열 |

그리고 `AlbumManager.RegisterMusicIDToAlbum()`으로 ID↔앨범을 등록하고, 이 커스텀 곡의 **템플릿 곡**
(캐릭터의 첫 원본 곡, 없으면 목록 첫 곡)을 기록합니다.

**MusicID 범위**: 원본 곡은 0~53(`MusicID.DLC2_02_DATA_END` = 53), `SAVEABLE_ID_END` = 512입니다.
54~511은 비어 있어 세이브 배열(`playerMusicData[]`)에도 슬롯이 있습니다. 최대 458곡입니다.
번호는 앨범 순서로 정해지므로 폴더 구성이 바뀌면 달라집니다([알려진_문제.md](../maintenance/알려진_문제.md) C4).

## 2. 곡 선택 (`AudioClipPatch`)

**대상**: `cMusicSelectSceneUIUpdater.noticeChangedMusic(nextMusicID)` **postfix**

- 커스텀 ID가 아니면: 텍스트 교체 끄기, 커스텀 선택 해제, 커스텀 프리뷰 정리 + 원본 프리뷰/환경음 복원.
- 커스텀 ID면(같은 ID 반복 알림은 무시):
  1. `AlbumManager.SelectAlbumByMusicID()`
  2. `CustomAssetManager.SetCustomChartSelected(true)`, `TextPatch.EnableTextReplacement(true)`
  3. `PreviewAudioManager.StopPreviewAndAmbient()`: 원본 프리뷰/환경음 음소거
  4. `ArtworkUpdater.UpdateArtwork()`: 커스텀 아트워크(캐시 또는 비동기 로드)
  5. `CustomBgmPlayer.InjectCustomBgm()`: 커스텀 프리뷰 BGM(0.15초 디바운스)

"커스텀 선택" 플래그(`CustomAssetManager.IsCustomChartSelected()`)는 이후 모든 주입의 스위치입니다.
주입 경로는 대부분 `ShouldInjectCustomContent()`(= 커스텀 선택 + 현재 씬이 `SoundPlayerScene`/`MoviePlayer_MovieSelect`가 아님)로 확인합니다.

## 3. 곡 시작 창 (`GameFlowHooks`)

원본 시작 창과 이후 흐름은 `soRythmGameMusicDataMap`에 실제로 있는 곡 데이터가 필요합니다. 커스텀 ID에는 데이터가 없으므로:

- **`coOpenPreMusicStartWindow` prefix**: `mCurentMusicId`를 템플릿 곡 ID로 바꿉니다. 원본은 이 값을 되돌리지 않으므로,
  이후 난이도·BPM·BGM 로드·노트 데이터 로드는 모두 템플릿 곡 기준으로 진행되고 모드가 그 위에 커스텀 데이터를 덮어씁니다.
- **`requestOpenWindow` postfix**: 시작 창의 `mArtworkImage`에 커스텀 아트워크를 넣습니다.
- **`setCurrentSelectDataToGameData` postfix**: 원본이 템플릿 곡 ID로 저장한 `lastPlayedMusicID`(와 `isNew`)를 실제 커스텀 ID로 고칩니다.
- **`soRythmGameMusicDataMap.getIsUsableMusicID` postfix**: 등록된 커스텀 ID를 "사용 가능"으로 인정해,
  곡 선택 화면에 다시 들어왔을 때 커서가 마지막 커스텀 곡에 놓이게 합니다.
- **`startRythmGame`/`backToPreScreen` prefix**: 커스텀 프리뷰 정리(곧 씬이 바뀌므로 원본 소스 복원 없이 상태만 버림).

`mCurentMusicId` 자체를 커스텀 ID로 되돌리면 컷인 씬에서 멈추는 문제가 있었습니다([HOOK_MAP.md](../maintenance/HOOK_MAP.md)).

## 4. 플레이와 결과

- 노트: [노트_생성_및_변환_파이프라인.md](../bms/노트_생성_및_변환_파이프라인.md)
- BGM/BGA/아트워크: [BGM_BGA_관리_시스템.md](BGM_BGA_관리_시스템.md), [커스텀_에셋_로딩_시스템.md](커스텀_에셋_로딩_시스템.md)
- 제목: [텍스트_패치_시스템_분석.md](텍스트_패치_시스템_분석.md)
- 결과 씬: `ResultSceneUpdaterPatch`가 `initializePreFade` **prefix**에서 `sceneInitParam.musicData.id`를 커스텀 ID로 바꿔
  기록이 템플릿 곡 슬롯에 저장되지 않게 하고, **postfix**에서 곡 제목(`mMusicNameText`), 플레이한 난이도의 레벨(`mMusicLVUI`),
  아트워크(`mArtWorkImage`, 페이드 시작 가능 시점까지 대기)를 바꿉니다.

템플릿 곡의 데이터 중 일부(오프셋, 기본 BPM 등)는 커스텀 차트에도 그대로 적용됩니다([알려진_문제.md](../maintenance/알려진_문제.md) B2).

## 로그로 확인하기

```
[AlbumManager] MusicID-앨범 매핑 등록: 54 -> shut up
[MusicScrollViewHooks] 커스텀 곡 주입 완료: 5개 (총 59개)
[AlbumManager] MusicID로 앨범 선택: shut up (MusicID: 54)
[GameFlowHooks] setCurrentSelectDataToGameData 보정: lastPlayedMusicID GVA1_007 -> 57 (isRhythmGameStart=True)
[NoteArrayHooks] BMS 노트 교체 완료: 358개
```

- 곡이 목록에 없으면: `hwa` 아래 폴더에 파일이 있는지, 로그에 `앨범 등록`과 `커스텀 곡 주입 완료`가 있는지 확인합니다.
- 곡을 추가했으면 게임을 다시 시작해야 합니다.
