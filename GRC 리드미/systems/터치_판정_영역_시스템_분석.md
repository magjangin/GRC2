# 터치 판정 영역 시스템 분석

## 개요

이 문서는 게임이 화면 터치(또는 마우스 클릭)를 어느 서브레인(Lane_1/2/3)에 대한 입력으로
인식하는지 결정하는 `cFairyJudgeCircleTouchAreas` 시스템을 설명합니다. GRC2의 판정 관련
기능(`JudgePerfectPatch`, `JudgmentBarPatch`, `NoteSwayPatch` 등)이 "판정은 화면 좌표가 아니라 레인과 시간으로
결정된다"는 전제를 두는 것도 이 구조를 확인했기 때문입니다.

## 핵심 클래스: `cFairyJudgeCircleTouchAreas`

```csharp
public class cFairyJudgeCircleTouchAreas : MonoBehaviour
{
    [SerializeField]
    [EnumdArray(typeof(NoteSubLaneType))]
    private cEditorVisualRect[] mTouchRect;

    public void getSubLaneTypeFromScreenPos(Vector2 screenPos, ref bool[] retIsSubLaneTouchArray)
    {
        // index 0(Lane_1), 2(Lane_3), 1(Lane_2) 순서로 각각 개별 Rect.Contains(screenPos) 체크
    }
}
```

- `mTouchRect`는 `NoteSubLaneType`(Lane_1/Lane_2/Lane_3) 크기에 맞춰 **정확히 3개**입니다.
- `cFairyModeNotesManager.mJudgeCircleTouchAreaArray`는 `NoteLaneLeftRight`(Left/Right) 크기의
  배열이라, 좌/우 각각 이 컴포넌트를 하나씩 가지고 있습니다 — **좌 3개 + 우 3개, 총 6개** 박스.
- 클래스 이름은 "JudgeCircle"이지만 실제 판정은 원(circle) 거리 계산이 아니라
  **`Rect.Contains(screenPos)` 사각형 히트박스**입니다. 각 박스는 `cEditorVisualRect`로
  에디터에서 디자이너가 배치한 사각 영역입니다.
- 터치가 어느 서브레인 박스에 들어왔는지는 `onTouchStart4Judge` (`cFairyModeNotesManager.cs`)가
  화면 좌표를 받아 이 메서드로 조회하고, 그 결과(`mTempIsTouchSubLaneArray`)로
  `getNearestJudgeNote`/`judgeTapAndHoldStartNote`를 호출해 실제 판정까지 이어집니다.
- 판정 자체(등급 계산)는 이 박스와 무관하게 시간(`perfectSample` vs `currentJudgeSample`)만
  비교합니다. 박스는 "어느 레인을 눌렀는지"만 결정하고, "얼마나 정확히 눌렀는지"는 결정하지
  않습니다.

## 향후 계획

3개 사각 박스(좌/우 각 Lane_1/2/3)의 **모양을 개별적으로 커스터마이징**할 수 있게 하는 기능을
나중에 추가할 계획입니다.

### `cEditorVisualRect` 구조 (2026-09-28 `Decompiled/`로 확인)

```csharp
[RequireComponent(typeof(RectTransform))]
[ExecuteAlways]
public class cEditorVisualRect : MonoBehaviour
{
    public RectTransform _rectTransform;   // Awake에서 GetComponent
    private Rect mRect;
    [SerializeField] private bool mIsEditorVisible = true;

    public Rect Rect
    {
        get
        {
            mRect.center = (Vector2)_rectTransform.position + _rectTransform.rect.center;
            Vector2 size = _rectTransform.rect.size;
            size.x *= _rectTransform.lossyScale.x;
            size.y *= _rectTransform.lossyScale.y;
            mRect.size = size;
            return mRect;
        }
    }
}
```

- `Rect`는 읽을 때마다 **`RectTransform`에서 새로 계산**합니다. 그래서 `mRect`를 덮어써도 다음 판정 때 다시 계산되어 소용없습니다.
- 박스 위치·크기를 바꾸려면 각 박스의 `RectTransform`(`position`/`anchoredPosition`, `sizeDelta`, `localScale`)을 바꿔야 합니다.
- 결과는 화면(월드) 좌표 기준 사각형이며, 판정은 `getSubLaneTypeFromScreenPos()`에서 `Rect.Contains(screenPos)`로 합니다.
