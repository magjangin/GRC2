# 텍스트 패치 시스템 분석

플레이·로딩·결과 화면에 나오는 템플릿 곡 제목을 커스텀 곡 제목으로 바꾸는 [`TextPatch`](../../GRC2/Harmony/TextPatch.cs)를 설명합니다.
(2026-09-28 코드 기준)

## 후킹 대상

`[HarmonyPatch]` 특성으로 선언되어 모드 시작 시 `PatchAll()`로 등록됩니다.

| 대상 | 방식 |
|------|------|
| `UnityEngine.UI.Text.set_text` | Prefix, `ref string value` |
| `TMPro.TMP_Text.set_text` | Prefix, `ref string value` (`TextMeshPro`/`TextMeshProUGUI` 공통) |

게임 전체의 모든 텍스트 대입이 이 prefix를 거칩니다.

## 교체 조건

`SetTextPrefix(ref string value)`는 아래를 순서대로 확인합니다.

1. `value`가 비어 있지 않을 것
2. 교체 스위치(`_isTextReplacementEnabled`)가 켜져 있을 것
   - 켜짐: 곡 선택 화면에서 커스텀 곡으로 커서가 갔을 때(`AudioClipPatch`)
   - 꺼짐: 원본 곡으로 커서가 갔을 때
3. 플레이·로딩·결과 씬일 것: `BgmBgaInjector.IsPlayScene()`이 true이거나, 현재 씬 이름이
   `FairyModeScene`, `PlayMovieScene`, `RenderCutinScene`, `RythmGameResultScene` 중 하나
4. 아래 중 하나에 해당할 것
   - 현재 커스텀 MusicID에 등록된 원본 제목이 `value` 안에 **포함**됨
   - `value`가 등록된 원본 제목(템플릿 곡 제목들) 중 하나와 **정확히 같음**
5. 현재 앨범의 `SongInfo`가 있을 것

조건을 모두 만족하면 `value`를 **통째로** `SongInfo.Title`로 바꾸고 로그를 남깁니다.

```
[TextPatch] 텍스트 교체 스위치: ON
[TextPatch] ✅ 텍스트 교체: '<템플릿 곡 제목>' -> 'shut up'
```

## 원본 제목 등록

`AlbumManager.RegisterOriginalTitle(템플릿 곡 ID, 제목)`으로 등록되며, 등록 시점은 두 곳입니다.

- 곡 목록 주입 시: 커스텀 곡마다 정한 템플릿 곡의 제목
- 곡 시작 창을 열 때: 실제로 빌려 쓴 템플릿 곡의 제목

## 곡 선택 화면은 대상이 아님

곡 선택 씬(`MusicSelectScene_Hasegawa`)은 3번 조건에 걸려 교체하지 않습니다. 곡 목록의 커스텀 곡 제목은 TextPatch가 아니라
목록 항목의 `songTitle` 자체를 커스텀 제목으로 만들어 넣는 방식입니다([커스텀_곡_주입_시스템_분석.md](커스텀_곡_주입_시스템_분석.md)).

결과 씬의 곡 제목은 `ResultSceneUpdaterPatch`가 `mMusicNameText`에 직접 넣기도 합니다.

## 주의사항

- 원제목을 포함한 문자열이면 문자열 전체가 커스텀 제목으로 바뀝니다(앞뒤 문구가 사라짐).
- 스위치가 켜진 동안 모든 텍스트 대입마다 원본 제목 HashSet을 새로 만듭니다([알려진_문제.md](../maintenance/알려진_문제.md) D3).
  세부 비용(H9): 스위치가 꺼져 있으면 조건 2에서 바로 끝나지만, 곡 선택에서 커스텀 곡을 고르는 동안에는 스위치가 켜져 있어
  곡 선택 씬의 모든 텍스트 대입이 `IsPlayOrLoadingScene()`의 `SceneManager.GetActiveScene().name`(문자열 할당)까지 갑니다.
  플레이 씬에서는 점수·콤보 등 텍스트가 바뀔 때마다 `GetCurrentMusicID()`(딕셔너리 선형 탐색)와 `GetAllOriginalTitles()`(HashSet 생성)가
  실행됩니다.
- 곡 선택 화면에서 일시정지 메뉴로 돌아온 경우 등 곡 선택 씬 진입 시 `BgmBgaInjector.ResetPlaySceneState()`로 플레이 씬 상태를 끕니다.
  씬 이름을 `StartsWith("MusicSelectScene")`로 확인하는 이유는 [HOOK_MAP.md](../maintenance/HOOK_MAP.md)에 있습니다.
