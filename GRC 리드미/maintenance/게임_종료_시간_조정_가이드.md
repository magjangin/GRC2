# 게임 종료 시간 조정 가이드

커스텀 BGM 길이에 맞춰 곡이 끝나도록 하는 모드 코드([BgmGameEndMonitor.cs](../../GRC2/Injectors/BgmGameEndMonitor.cs))와
문제 해결 방법입니다. 원본 게임의 종료 방식은 [게임_종료_로직.md](게임_종료_로직.md)를 먼저 봅니다. (2026-09-28 코드 기준)

## 요약

- 원본은 템플릿 곡의 페이드 샘플에서 곡을 끝냅니다. 커스텀 BGM이 더 길면 그대로 두면 일찍 끝납니다.
- 모드는 **커스텀 곡일 때만**(`ShouldInjectCustomContent()`) 종료 시각을 `max(커스텀 BGM 길이, 마지막 노트 시간)`으로 바꿉니다.
- 바꾸는 필드는 4개입니다. 하나라도 빠지면 BGM이나 화면 페이드가 원래 시각에 끝나 곡이 일찍 종료됩니다.

## 목표 시간 정하기: `BgmFinishTimeManager`

| 메서드 | 호출 시점 | 동작 |
|--------|-----------|------|
| `Reset()` | 곡 시작 버튼(`startRythmGame`), 플레이 씬 로드 | 목표 시간 = 0 |
| `SetFinishTime(bgmLength)` | `BgmLoader`가 BGM을 넣은 직후 | 목표 시간 = max(BGM 길이, 마지막 노트 시간) |

마지막 노트 시간은 `mFairyNoteCreateDataArray`의 최상위 노트 중 가장 큰 `perfectSample` ÷ 48000입니다.

## 원본 코루틴 감싸기: `BgmGameEndMonitor`

```csharp
[HarmonyPatch(typeof(cRythmGameManager), "coMonitorGameEnd")]
internal static class BgmGameEndMonitor
{
    [HarmonyPostfix]
    public static void MonitorGameEndPostfix(cRythmGameManager __instance, ref IEnumerator __result)
    {
        if (__instance == null || __result == null || !CustomAssetManager.ShouldInjectCustomContent())
            return;
        __result = WaitForTimingAndRunOriginal(__instance, __result);
    }
}
```

`WaitForTimingAndRunOriginal()`:

1. 목표 시간이 정해질 때까지 최대 **15초**(실제 시간) 기다립니다. 커스텀 선택이 풀리면 바로 멈춥니다.
2. 목표 시간이 있으면 4개 필드를 고칩니다. 없으면 경고를 남기고 원본 값으로 진행합니다.
3. 원본 `IEnumerator`를 끝까지 실행합니다(원본의 점수 보정, 페이드, 클리어 연출, 씬 전환은 그대로).

원본 코루틴이 첫 줄에서 필드를 지역 변수로 복사하기 때문에, 원본의 첫 `MoveNext()` 전에 고치는 이 구조가 필요합니다.

## 4개 필드

목표 시간을 T초라 하면(`ToSample` = `round(초 × 48000)`, int 범위를 넘으면 `int.MaxValue`):

| 필드 | 값 |
|------|----|
| `musicFadeOutStartSample` | T − 1초 |
| `musicFadeOutEndSample` | T |
| `screenFadeOutStartSample` | T − 1.5초 |
| `screenFadeOutEndSample` | T |

예: BGM 158.016초 → `musicFadeOutEndSample` = 7,584,768, `musicFadeOutStartSample` = 7,536,768, `screenFadeOutStartSample` = 7,512,768.

## 로그

```
[BgmLoader] BGM 주입 성공
[BgmFinishTimeManager] 게임 종료 시간 설정: 213.525초 (BGM: 213.525초, 마지막 노트: 196.875초)
[BgmGameEndMonitor] 원본 종료 코루틴에 커스텀 종료 시간 적용: 213.525초
```

## 문제 해결

| 증상 | 확인할 것 |
|------|-----------|
| 곡이 일찍 끝남 | 로그에 `커스텀 종료 시간 적용`이 있는지. 대신 `커스텀 BGM 종료 시간이 준비되지 않아 원본 차트 시간을 사용합니다`가 있으면 BGM 주입이 15초 안에 끝나지 않은 것 → `[BgmLoader]` 로그(타임아웃, 파일 크기)를 봅니다. |
| 곡이 너무 늦게 끝남 | BGM 파일 끝에 무음이 긴지 확인합니다. 종료 시각은 BGM 길이 그대로입니다. |
| 마지막 홀드가 잘림 | 끝 노트는 종료 시간 계산에 들어가지 않습니다([알려진_문제.md](알려진_문제.md) B3). BGM 끝에 여유를 둡니다. |
| 노트가 점점 밀림 | BGM이 48kHz인지 확인합니다(알려진 문제 B1). |
| 곡 끝에 `All Note Count Invalid` | 템플릿 곡보다 긴 차트의 노트 수 문제입니다(알려진 문제 B2). |
