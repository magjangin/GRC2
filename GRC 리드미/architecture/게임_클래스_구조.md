# 게임 클래스 구조

모드가 직접 읽거나 쓰는 게임 클래스의 필드·메서드만 정리합니다. 모두 `Decompiled/`에서 확인한 이름이며,
원본의 오타도 그대로입니다. 네임스페이스를 따로 적지 않은 것은 `IntiCreates`입니다. (2026-09-28 기준)

## 곡 선택

### `soRythmGameMusicDataMap` (ScriptableObject)

- `MusicID` enum: 0~53 실제 곡, `SAVEABLE_ID_END = 512`, `UNIQUE_TOP = 8000`([Enum_및_타입_시스템_관리.md](../harmony/Enum_및_타입_시스템_관리.md))
- `MusicData` (**struct**): `id`, `charactorID`, 난이도 데이터 등. 값 복사이므로 `sceneInitParam.musicData.id`를 바꿔도 원본 목록은 그대로
- `MusicData`의 크레딧 게터 7개: `getArtistText()`, `getLylicistText()`, `getComposerText()`, `getArrangerText()`,
  `getNoteCreaterText()`(채보), `getCDTitleText()`, `getGameTitleText()`. 각 enum 값을 `MusicInformation` 문자열 표에서 찾고,
  enum이 `INVALID`면 `INVALID_MUSIC_INFO_DISP`(`"-"`)를 돌려줍니다. 모드가 커스텀 곡일 때 값을 바꿉니다(`CreditTextPatch`)
- `getMusicDataFromId(id)`(목록에 없는 ID면 `new MusicData { id = Invalid }`, 나머지 필드는 기본값 0), `getIsUsableMusicID(id)`,
  `getSyncFromAddressable()`(DLC 곡 데이터는 `isDLCEnable` + `isExistAddressableKey`일 때만 추가)

### `cMusicSelectScrollView`

- `mCellHaviableMusicDataList` (private `List<MusicSelectScrollItemData>`)
- `initializeMusicDataByDefault()` (private): 목록을 비우고 `getMusicDataList()`로 다시 채움. `initialize()`와 `doFilterMusicList()`에서 호출

`MusicSelectScrollItemData(int index, MusicSelectData data)`의 `mMusicSelectData`는
`cMusicSelectScrollViewDataGetter.MusicSelectData` **struct**입니다. 모드가 쓰는 필드:
`musicID`, `songTitle`, `songTitleForSort`, `songTitleRuby`, `songTitleRubyDirect`, `musicLVArray`, `isFull`, `isCurrentLock`,
`isNeedDispNew`, `haveMV`, `defaultSortPrio`, `sorceTitle`, `artistID`(`PCD.MainCharactor`), `highScoreArray`, `clearBadgeArray`.

크레딧 표시는 두 곳뿐이고 둘 다 위 게터로 읽습니다.

- `cMusicSelectArtWorkManager.requestSetMusicData(bool isInstant, MusicID musicID)` (public): 아트워크 로딩이 끝났으면
  `getMusicDataFromId(musicID)`의 게터 7개로 상세 패널(`mTextArray`, `TextType` 순서: 아티스트·작사·작곡·편곡·채보·CD·원작 게임)을
  채웁니다. 음악 플레이어용(`mIsMusicPlayer`)이면 작사·작곡·편곡만 한 줄로 씁니다. 곡 선택(`coChangePreviewBGM`, 씬 초기화),
  음악 플레이어, 무비 플레이어에서 부릅니다.
- `cPreRythmnGameStartScreen.coInitialize(MusicData, Difficulty, AudioSource, float)` (public IEnumerator): 플레이 씬의 곡 시작
  화면. 첫 `MoveNext`에서 작사·작곡·편곡 게터로 `"작사: …  작곡: …  편곡: …"` 한 줄을 만듭니다(라벨은 `MusicSelectScene` 표의
  `ARTWORK_LYRICST`/`ARTWORK_COMPOSER`/`ARTWORK_ARRANGER`, fr이면 구분자 `" : "`).

## 사운드·DLC

- `sSoundManager2D`: BGM·환경음·효과음이 `AudioSource` 풀을 공유합니다. `getPlayableData()`는 `clip == null`이고
  관리 씬이 없는 슬롯을 빈 슬롯으로 봅니다. `requestLoopPlay`, `requestPlayOneShot`, `requestFadeAudio`.
- `cDlcDirector`: `DlcList`(`Dictionary<int, cDlcInfo>`, `cDlcInfo.mMountPath`), `Initialize()`(`Start`에서 호출, 스팀이 초기화됐으면
  `GetDLCCount`/`BGetDLCDataByIndex`/`BIsDlcInstalled`로 목록 작성), `IsInitialize()`, `coMount`, `IsNotYetPurchased()`.
  마운트 경로는 `DataAddon/<번호>`(작업 폴더 기준).
- `sAddressableDirector`: `coInitialize()`가 `cDlcDirector`를 붙이고 `IsInitialize()`를 기다린 뒤 `coCheckDLC()`로 각 DLC의
  `catalog.json`을 불러옵니다. `isUsableDlc(index)`, `isNotYetPurchased()`.
- `IntiCreates.Application.isDLCEnable(measure, minor)`: `isUsableDlc`를 호출합니다.
