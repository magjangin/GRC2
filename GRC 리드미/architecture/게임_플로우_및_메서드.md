# 게임 플로우 및 메서드

게임을 켜서 커스텀 곡을 한 판 끝낼 때까지, 원본 게임의 흐름과 모드가 끼어드는 지점을 시간 순으로 정리합니다.
(2026-09-28 기준. 괄호 안은 모드 코드)

## 1. 모드 초기화 (게임 첫 씬 전)

`SceneDetector.OnInitializeMelon()`:

1. `PatchAll()`로 모든 `[HarmonyPatch]` 적용
2. `<게임 폴더>/hwa` 준비, `CustomKeySettings.Initialize()`로 `savecustomkey/config.txt` 읽기(없으면 기본 파일 생성)
3. `AlbumManager.ScanAlbums()`, 곡 정보 확인, 현재 앨범 아트워크 미리 읽기
4. 모든 앨범의 모든 BMS 파싱 → `NoteArrayHooks.UpdateBmsNotes()`
   (BGA/BGM 경로는 따로 초기화하지 않습니다. 주입 루프가 매번 현재 앨범에서 읽습니다.)

## 2. 부팅 (`BootScene`)

- 스팀: `SteamManager.Awake`가 `SteamAPI.Init()`을 호출합니다. 실패해도 원본은 계속 진행합니다
  (`SteamApiHijacker`는 실패를 true로 바꿈 → [알려진_문제.md](../maintenance/알려진_문제.md) A3).
- `sAddressableDirector.coInitialize()`: `cDlcDirector` 초기화를 기다린 뒤(`SteamApiHijacker`가 `DataAddon` 폴더 등록)
  DLC 카탈로그를 불러옵니다.
- `cBootSceneManageObject`: 세이브(`gnrccData`)를 읽습니다. 없거나 깨졌으면 `Saved`가 될 때까지 첫 세이브를 반복합니다
  (`BlockSave=1`이면 끝나지 않음 → 알려진 문제 A1).

## 3. 곡 선택 (`MusicSelectScene_Hasegawa`)

| 원본 | 모드 |
|------|------|
| `cMusicSelectScrollView.initializeMusicDataByDefault()` — 곡 목록 작성 | 캐릭터별 첫 곡 등록, 커스텀 곡 추가 (`MusicScrollViewHooks`) |
| `getMusicIDUsable(lastPlayedMusicID)` — 마지막 곡으로 커서 | 커스텀 ID도 사용 가능으로 인정 (`GameFlowHooks`) |
| `noticeChangedMusic(id)` — 커서 이동, 프리뷰·아트워크 교체 시작 | 커스텀이면 앨범 선택·음소거·커스텀 프리뷰/아트워크 (`AudioClipPatch`) |
| `cMusicSelectArtWork.requestSetArtworkSprite()` | 커스텀 스프라이트로 교체 (`ArtWorkPatch`) |
| `coOpenPreMusicStartWindow()` — 곡 시작 창 | `mCurentMusicId`를 템플릿 곡으로 (`GameFlowHooks`) |
| `requestOpenWindow()` | 시작 창 아트워크 교체 |
| `startRythmGame()` → `setCurrentSelectDataToGameData(true)` | 커스텀 프리뷰 정리, 종료 시간 초기화, 저장된 ID를 커스텀 ID로 수정 |

## 4. 플레이 준비 (`FairyModeScene` + `PlayMovieScene` + `RenderCutinScene`)

씬 로드마다 `SceneDetector.OnSceneWasLoaded()`가 설정 파일을 다시 읽고(결과 씬 제외), 프리뷰를 정리하고,
BGM/BGA 주입 루프를 시작합니다. 커스텀 곡이 선택된 상태면 현재 앨범의 BMS를 `NoteArrayHooks`에 넣고 아트워크 주입도 시작합니다
([씬_관리_및_라이프사이클.md](씬_관리_및_라이프사이클.md)).

원본 `cRythmGameManager` 초기화 코루틴:

```
mBeatManager.setClip(원본 BGM, isNeedLoad: true)
notesManager.requestInitialize(…)
   └─ loadFairyMusicDataFromID(템플릿 곡) → mNoteMusicData
   └─ createAllNote()     ← [NoteArrayHooks] 배열을 BMS 변환 결과로 교체
                           ← [AutoPlayPatch] AutoPlay=1이면 mIsCurrentAutoPlay 강제
                           ← [NoteSpeedChaosPatch] 속도 배율 캐시 초기화
initializeScoreAndKudos() → countAllJudgeNum()
컷인·시작 화면 연출
mBeatManager.requestPlayAudio()
StartCoroutine(coMonitorGameEnd())   ← [BgmGameEndMonitor] 감싸기
```

참고: `createAllNote`는 곡 선택 씬의 옵션 미리보기 창(`cMusicSelectPreviewWindowManager`)에서도 창을 열 때와 루프 지점마다 호출됩니다.
모드의 `createAllNote` prefix(`NoteArrayHooks`)는 `BgmBgaInjector.IsPlayScene()`이 참일 때만, 즉 플레이 씬에서만 BMS를 주입하므로
미리보기 호출은 건드리지 않습니다(2026-10-04 수정, [알려진_문제.md](../maintenance/알려진_문제.md) H1).

모드의 BGM/BGA 주입 루프는 2초 간격으로 돌며, 로그상 씬 로드 약 3초 뒤 BGM을 바꿔 처음부터 다시 재생합니다.
노트 시계가 BGM 샘플 위치이므로 노트는 새 BGM을 따라갑니다.

## 5. 플레이 중

- 매 프레임 `cNotecWorkBase.simulate(currentSample)`로 노트가 움직입니다(`NoteSwayPatch`가 x 위치에 흔들림 추가,
  `NoteSpeedChaosPatch`가 `getNoteSpeed()`에 배율).
- 입력 → `cFairyModeNotesManager.onTouchStart4Judge` → 터치 박스로 레인 결정 → 시간 차이로 판정 →
  `cNotecWorkBase.onJudgeMent(OnJudgeParam)` (`JudgePerfectPatch`가 AllPerfect=1이면 `PERFECT`로, `JudgmentBarPatch`가
  그보다 먼저 잡아 둔 실제 등급과 `subSample`을 판정바로 전달).
- Space/Esc: 일시정지 열기/계속하기 (`SceneDetector.OnUpdate`).
- 원본 BGA 교체 코루틴은 커스텀 BGA가 들어가면 멈춥니다(`BgaCrossfadePatch`).

## 6. 곡 종료

`coMonitorGameEnd()`가 페이드 샘플에 도달하면 BGM·화면을 페이드하고 클리어 연출 후 결과 씬으로 갑니다.
커스텀 곡은 모드가 페이드 샘플을 커스텀 BGM 길이로 바꿉니다([게임_종료_로직.md](../maintenance/게임_종료_로직.md)).

## 7. 결과 (`RythmGameResultScene`)

| 원본 | 모드 |
|------|------|
| `initializePreFade(sceneInitParam)` — `playerMusicData[musicData.id]` 기록 비교·갱신, `setDirty()` | prefix: `musicData.id`를 커스텀 ID로 (`ResultSceneUpdaterPatch`) / `BlockSave=1`이면 기록 4개 필드 스냅샷 (`RecordBlockPatch`) |
| | postfix: 제목·레벨·아트워크 교체 / 기록 원복, 이전 최고점 표시 0 |
| `coUpdateResultAnim()` | `BlockSave=1`이면 이전 최고점 0 |
| `requestGameDataSaveToFile()` | `BlockSave=1`이면 건너뜀 |

결과 씬에서는 설정 파일을 다시 읽지 않습니다. 플레이를 시작할 때의 `BlockSave` 값이 결과·저장까지 유지됩니다.

## 8. 복귀

- 결과 → 곡 선택, 또는 일시정지 메뉴 → 곡 선택(`backToMusicSelectScene`): 곡 선택 씬 로드 시 주입 정지·플레이 씬 상태 해제.
- 재시작(`gui_requestRetry`): 실제 씬 전환이므로 설정을 다시 읽고 4단계부터 반복합니다.
