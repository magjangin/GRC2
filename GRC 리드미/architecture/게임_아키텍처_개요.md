# 게임 아키텍처 개요

GUNVOLT RECORDS Cychronicle의 구조와, GRC2 모드가 그 위에 어떻게 얹히는지 한 장으로 정리합니다.
게임 쪽 내용은 `Decompiled/`(Assembly-CSharp 디컴파일, git 제외)로 확인한 것입니다. (2026-09-28 기준)

## 게임 환경

| 항목 | 값 |
|------|----|
| 개발사 | INTI CREATES |
| 엔진 | Unity 2021.3.31f1, Mono (`GUNVOLT_RECORDS_Cychronicle_Data/Managed`) |
| 게임 버전 | 1.1.0 |
| 에셋 | Addressables (DLC는 `DataAddon/<번호>/catalog.json`) |
| 스팀 | Steamworks.NET (`com.rlabrecque.steamworks.net.dll`). 현재 설치본은 Goldberg 에뮬레이터 `steam_api64.dll` 사용 |
| 모드 로더 | MelonLoader (net35 빌드), Harmony |

## 네임스페이스 (Assembly-CSharp)

| 네임스페이스 | 내용 |
|--------------|------|
| `IntiCreates` | 씬 매니저, UI 업데이터, 싱글톤 디렉터(`s*`), 곡 데이터(`soRythmGameMusicDataMap`), 세이브, DLC |
| `IntiCreates.RythmGame` | 노트 공통 enum(`NoteDirectionIndex`, `TurnDirection`, `NoteSize`, `JudgeType`, `ResultClearBadge`) |
| `IntiCreates.RythmGame.FairyMode` | 페어리 모드 enum(`NoteTypeId`, `NoteLaneLeftRight`, `NoteSubLaneType`) |
| `IntiCreates.SceneManage`, `.Work`, `.Motion`, `.Facial`, `.LylicsSpacer` | 씬 관리, 오브젝트 작업, 캐릭터 연출 |

이름 규칙: `c*`는 일반 `MonoBehaviour`, `s*`는 싱글톤(`SingletonMonoBehaviour<T>.Instance`), `so*`는 `ScriptableObject`.
원본 식별자의 오타(`Rythm`, `Sorce`, `turnDireciton`, `mCurentMusicId`, `mCellHaviableMusicDataList`)는 그대로 써야 합니다.

## 씬

| 빌드 인덱스 | 씬 이름 | 역할 |
|-------------|---------|------|
| 0 | `BootScene` | 초기화, 세이브 로드(없으면 첫 세이브 생성) |
| 1 | `LogoScene` | 로고 |
| 2 | `TitleScene` | 타이틀 |
| 6 | `MainMenuScene` | 메인 메뉴 |
| 7 | `MusicSelectScene_Hasegawa` | 곡 선택 |
| 3 | `FairyModeScene` | 리듬 게임 본체 (노트, 판정) |
| 4 | `PlayMovieScene` | 배경 영상(BGA) |
| 8 | `RenderCutinScene` | 시작 컷인 |
| 5 | `RythmGameResultScene` | 결과 |

플레이할 때는 `FairyModeScene` → `PlayMovieScene` → `RenderCutinScene` 순으로 함께 로드됩니다(로그 기준).
그 밖에 `SoundPlayerScene`, `MoviePlayer_MovieSelect` 같은 감상 모드 씬이 있고, 모드는 이 씬들에서 주입을 막습니다.
씬 식별 enum은 `SceneId`(Boot, Logo, Title, MainMenu, MusicSelect, RythmGame_Fairy, BackGround_Movie, RythmGame_CurinScene, RythmGame_Result, …)입니다.

## 핵심 게임 클래스

| 클래스 | 역할 | 모드와의 관계 |
|--------|------|---------------|
| `soRythmGameMusicDataMap` | 곡 목록 데이터, `MusicID` enum | 커스텀 ID 54~511 사용, `getIsUsableMusicID` 패치 |
| `cMusicSelectScrollView` | 곡 목록 스크롤 | `initializeMusicDataByDefault` postfix로 커스텀 곡 추가 |
| `cMusicSelectSceneUIUpdater` | 곡 선택 화면 전체(프리뷰, 시작 창) | 여러 훅 ([HOOK_MAP.md](../maintenance/HOOK_MAP.md)) |
| `FairyNoteEditorLoader` | 노트/곡 데이터 로더, `NoteCreateData`/`MusicData` 정의 | 모드가 `NoteCreateData`를 직접 생성 |
| `cFairyModeNotesManager` | 노트 생성·판정 | `createAllNote` prefix로 노트 배열 교체 |
| `cNotecWorkBase` | 노트 하나의 동작 | 판정·이동 관련 패치 |
| `cBGMBeatManager` | 플레이 BGM 재생, 노트 시계 | 커스텀 BGM 주입 |
| `cRythmGameManager` | 플레이 흐름, 일시정지, 곡 종료 | 종료 시간 보정, 일시정지 키 |
| `cPlayMovieSceneManager` | BGA 재생 | 원본 BGA 교체 코루틴 정지 |
| `cRythmGameResultSceneUpdater` | 결과 화면 | 제목·레벨·아트워크·세이브 ID 보정 |
| `sSaveDataDirector` | 세이브 | 기록 차단 |
| `sSoundManager2D` | `AudioSource` 풀 | 프리뷰 음소거 방식에 영향 |
| `cDlcDirector`, `sAddressableDirector` | DLC 마운트와 Addressables | DataAddon 등록 |

세부 필드와 메서드는 [게임_클래스_구조.md](게임_클래스_구조.md)를 봅니다.

## 모드 구조

```
GRC2/
├── Core/        SceneDetector(MelonMod 진입점), AlbumManager, CustomAssetManager,
│                CustomKeySettings(config.txt), GameHud(판정바), PlaySceneArtworkInjector
├── Harmony/     [HarmonyPatch] 클래스와 보조 클래스(CustomBgmPlayer, PreviewAudioManager)
├── Injectors/   BGM/BGA 주입, BGA-BGM 동기화, 곡 종료 보정(BgmGameEndMonitor)
├── Parsers/     BMS 파서, info.txt 파서, 요약 출력
├── Builders/ Converters/ Processors/   BmsNote → NoteCreateData 변환
└── Helpers/     enum 매핑, 예외 로깅, 초↔샘플 변환
```

- 게임 DLL(`Assembly-CSharp.dll`, Steamworks)을 컴파일 타임에 직접 참조합니다. 비공개 필드는 `AccessTools.FieldRefAccess`
  대리자로 접근하고, 비공개 메서드 호출은 `setPauseButtonPusable` 하나뿐입니다(`AccessTools.MethodDelegate`).
- 모든 패치는 `[HarmonyPatch]` 특성으로 선언하고 `SceneDetector.OnInitializeMelon()`에서 `PatchAll()`을 한 번 호출합니다.
- 사용자 데이터: `<게임 폴더>/hwa/`(커스텀 곡), `<게임 폴더>/savecustomkey/config.txt`(설정).
