# 씬 관리 및 라이프사이클

모드가 씬마다 무엇을 하는지와, 씬을 넘어 유지되는 모드 상태를 정리합니다.
씬 처리는 모두 [SceneDetector.cs](../../GRC2/Core/SceneDetector.cs)(`MelonMod`) 안에 있습니다. 예전의 `SceneHandler` 클래스는
2026-07-26에 삭제되었습니다. (2026-09-28 기준)

## MelonMod 콜백

| 콜백 | 하는 일 |
|------|---------|
| `OnInitializeMelon` | Harmony 적용, 설정·앨범·BMS·주입기 초기화 (한 번). 실패해도 예외를 로그로 남기고 `_isInitialized = false`로 둠 |
| `OnSceneWasLoaded(buildIndex, sceneName)` | 아래 씬 라우팅 |
| `OnUpdate` | 1초마다 설정 파일 변경 감지(로그만), 플레이 씬에서 Space/Esc 일시정지 처리 |
| `OnGUI` | 플레이 씬에서 판정바 그리기 (`GameHud`) |

초기화가 끝나지 않았으면 세 콜백 모두 아무것도 하지 않습니다.

## 씬 라우팅 (`OnSceneWasLoaded`)

모든 씬에서 먼저: 결과 씬이 아니면 `CustomKeySettings.Reload()`(파일이 바뀌었을 때만 다시 읽음).

| 씬 | 처리 |
|----|------|
| `FairyModeScene`, `PlayMovieScene` | 커스텀 프리뷰 정리 → 커스텀 곡이면 현재 앨범 에셋 다시 적재 + 플레이 씬 아트워크 주입 → `StartInjection(isPlayScene: true)` → 목표 종료 시간 초기화 |
| `RenderCutinScene` | 커스텀 프리뷰 정리 → `StartInjection(isPlayScene: true)` → 커스텀 곡이면 앨범 에셋 다시 적재 + 아트워크 주입 |
| `RythmGameResultScene` | `StopInjection()` + `ResetPlaySceneState()` (설정 다시 읽기도 하지 않음) |
| `MusicSelectScene*` (`StartsWith`) | `StopInjection()` + `ResetPlaySceneState()` |
| `SoundPlayerScene`, `MoviePlayer_MovieSelect` | 위와 같고, 커스텀 곡 선택도 해제 |
| 그 밖 (`BootScene`, `LogoScene`, `TitleScene`, `MainMenuScene` 등) | 플레이 씬 상태면 커스텀 곡일 때 에셋 다시 적재 + 아트워크, 아니면 `StartInjection(isPlayScene: false)` |

곡 선택 씬의 실제 이름은 `MusicSelectScene_Hasegawa`라 접두사로 비교합니다. 정확히 `"MusicSelectScene"`만 비교하던 때는
일시정지 메뉴로 곡 선택에 돌아와도 플레이 씬 상태가 풀리지 않아 제목·아트워크 교체가 곡 선택 화면에 남았습니다
([HOOK_MAP.md](../maintenance/HOOK_MAP.md)).

"앨범 에셋 다시 적재"(`ReloadCurrentAlbumAssets`)는 현재 앨범의 곡 정보와 BMS 노트를 갱신합니다.
BMS 파일이 바뀌었거나 노트가 비어 있을 때만 캐시에서 꺼내 `NoteArrayHooks.UpdateBmsNotes()`를 호출합니다
(노트가 0개면 호출하지 않음 → [알려진_문제.md](../maintenance/알려진_문제.md) C2).

## 씬을 넘어 유지되는 상태

| 상태 | 위치 | 켜짐 | 꺼짐 |
|------|------|------|------|
| 커스텀 곡 선택 | `CustomAssetManager.isCustomChartSelected` | 커스텀 곡으로 커서 이동 | 원본 곡으로 커서 이동, 감상 모드 씬 |
| 플레이 씬 여부 | `BgmBgaInjector._isPlayScene` | 플레이/컷인 씬 로드 | 결과·곡 선택·감상 씬 로드 |
| 텍스트 교체 스위치 | `TextPatch._isTextReplacementEnabled` | 커스텀 곡 선택 | 원본 곡 선택 |
| 현재 앨범 | `AlbumManager._currentAlbum` | 커스텀 곡 선택 | (유지) |
| 주입할 BMS 노트 | `NoteArrayHooks._bmsNotes` | 플레이 씬에서 갱신 | (유지) |
| 목표 종료 시간 | `BgmFinishTimeManager` | BGM 주입 | 곡 시작 버튼, 플레이 씬 로드 |
| 마지막 처리한 MusicID | `AudioClipPatch._lastHandledMusicId` | 커스텀 곡 선택 | 원본 곡 선택 (씬 전환으로는 초기화되지 않음 → 알려진 문제 D2) |
| 설정 값 | `CustomKeySettings` | 시작, 결과 씬 외 씬 로드 | — |

곡 선택 화면에서 원본 곡으로 커서를 옮기기 전까지는 "커스텀 곡 선택" 상태가 유지되므로, 커스텀 곡을 플레이하고
돌아온 직후의 곡 선택 화면도 커스텀 상태로 시작합니다.

## `DontDestroyOnLoad` 오브젝트

- `CustomPreviewBGM`: 커스텀 프리뷰용 `AudioSource` (`CustomBgmPlayer`). 한 번 만들어 계속 재사용합니다.

그 밖의 모드 상태는 모두 정적 필드이며, 게임 오브젝트 참조(`AudioSource`, `Image`, `VideoPlayer`)는 씬이 바뀌면
Unity null이 되므로 쓸 때마다 확인하거나 다시 찾습니다.
