# 게임 코드 분석 문서 인덱스

게임 내부 구조와 모드 동작을 다룬 문서를 주제별로 모았습니다. (2026-09-28 기준)

## 게임 코드를 확인하는 방법

예전 문서는 "게임 코드를 직접 볼 수 없어 추정한다"고 적혀 있었지만, 지금은 저장소 루트의 `Decompiled/`에
`Assembly-CSharp.dll` 디컴파일 결과가 있습니다(저작권상 git에는 넣지 않음, `.gitignore`의 `/Decompiled/`).

- 게임 타입·필드·메서드는 `Decompiled/IntiCreates*/`에서 확인합니다.
- Steamworks.NET 동작은 `com.rlabrecque.steamworks.net.dll`을 `ilspycmd`로 따로 디컴파일해 확인합니다.
- 모드는 게임 DLL을 직접 참조하므로, 게임 업데이트로 이름이 바뀌면 대부분 컴파일 오류로 드러납니다.
  문자열로 지정한 패치 대상 메서드와 `FieldRefAccess` 필드 이름만 따로 확인이 필요합니다([HOOK_MAP.md](../maintenance/HOOK_MAP.md) 2026-08-09 항목).
